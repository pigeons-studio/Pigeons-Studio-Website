# Prototype ORCA//GLYPH — Pigeons Studio

Prototype de navigation pour le site : huit étages en 3D, chacun sous un signe de l'alphabet partagé As-Simt.
La molette traverse les étages, un clic entre dans un étage et la page passe en 2D.

- Page : `public/proto/index.html` (autonome : three.js et la police se chargent depuis un CDN)
- Films de la section « futurs projets » : `public/proto/films/`
- Contenu repris de `messages/fr.json`

En local : `npm run dev`, puis http://localhost:3000/proto/index.html
